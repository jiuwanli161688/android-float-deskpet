## 1.3.0

- 本机登记 / 走进来：账号仅字母数字 5–18 位，提交时校验；账号、暗号、称呼、幸福点只留在这台手机，不申请网络权限
- 登录后进入「今日陪伴」（不再叫首页）；右下角固定小按钮打开右侧菜单（换装、外观、请来身边、开关）
- 我的小窝：称呼、账号、幸福点；可重新认识 TA、先离开一会儿
- 陪伴入驻：不确定性别时默认他；不取名时从名字册轮流选；入驻页用更大的角色图
- 女角色风格：御姐 / 萝莉 / 清纯风；男角色：温柔邻家 / 清爽少年 / 沉稳学长；男生仍不提供睡衣
- 归档 APK：`releases/float-deskpet-1.3.0-debug.apk`、`releases/float-deskpet-1.3.0-release.apk`

## 1.2.0

- 自主走路起步/停步缓入缓出，转向不再瞬间掉头；轻跳改为落地更软的弧线，待机呼吸和打盹切换更缓
- 新增男角色「阿辰」：日常 + 出行两套帧，独立气泡词库和长按菜单文案；女生三套换装保留
- 首次启动先选男/女再起名（默认杏杏 / 阿辰）；设置里可改角色和名字；通知栏标题和主页展示自定义名字
- 可选系统 TTS 读气泡，按性别选声线，没有对应声音时只调音高；静音同时关掉音效和语音；不联网
- 归档 APK：`releases/float-deskpet-1.2.0-debug.apk`、`releases/float-deskpet-1.2.0-release.apk`

## 1.1.1

- 气泡改为独立悬浮层：优先在角色上方，贴顶时改到左/右侧或略下方，留出空隙且不挡住脸和身体，显示期间跟随移动并夹在屏幕内
- 自主移动不再只左右平移：斜向闲逛、行走轻跳、停顿转向、小弧线/两段路径、走向随机点后发呆或打盹；仍遵守安全边距、半藏探头、拖动与甩出
- 归档 APK：`releases/float-deskpet-1.1.1-debug.apk`、`releases/float-deskpet-1.1.1-release.apk`

## 1.1.0

- 自主行为：沿屏幕走动弹边、打盹、超时半藏探头；点探头或摇一摇唤回
- 手势：双击轮换表情；长按菜单（摸摸 / 喂食 / 睡觉）；甩出带惯性再停下
- 本地气泡：早午晚夜 + 互动句，贴在桌宠旁自动消失
- 心情 / 亲密度 0–100，随摸摸、喂食、冷落、时间变化，驱动表情和气泡池，写入 SharedPreferences
- 出现 / 点击 / 菜单 / 躲藏短音效，设置里可静音
- 三套换装：日常、睡衣、出行
- 低电量 / 充电本地气泡；喂食消耗本地零食并缓慢回复
- 息屏或半藏时暂停重动画
- 归档 APK：`releases/float-deskpet-1.1.0-debug.apk`、`releases/float-deskpet-1.1.0-release.apk`

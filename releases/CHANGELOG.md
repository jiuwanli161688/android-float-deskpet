# 更新记录

## 1.1.0

- 自主行为：沿屏幕走动弹边、打盹、超时半藏探头；点探头或摇一摇唤回
- 手势：双击轮换表情；长按菜单（摸摸 / 喂食 / 睡觉）；甩出带惯性再停下
- 本地气泡：早午晚夜 + 互动句，贴在桌宠旁自动消失
- 心情 / 亲密度 0–100，随摸摸、喂食、冷落、时间变化，驱动表情和气泡池，写入 SharedPreferences
- 出现 / 点击 / 菜单 / 躲藏短音效，设置里可静音
- 三套换装：日常、睡衣、出行
- 低电量 / 充电本地气泡；喂食消耗本地零食并缓慢回复
- 息屏或半藏时暂停重动画
- 归档 APK：`releases/float-deskpet-1.1.0-debug.apk`、`releases/float-deskpet-1.1.0-release.apk`

## 1.0.0

- 系统悬浮窗桌宠，前台服务 + 常驻通知（显隐 / 穿透 / 退出）
- 首次授权引导、设置页（大小 / 透明度 / 始终显示 / 穿透）
- 杏杏 Q 版帧动画：待机呼吸+眨眼，点击跳跃/挥手，拖完回弹
- 纯本地，无网络权限；附隐私说明与国产 ROM 省电提示
- 归档 APK：`releases/float-deskpet-1.0.0-debug.apk`、`releases/float-deskpet-1.0.0-release.apk`

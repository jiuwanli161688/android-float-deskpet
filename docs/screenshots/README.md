## 女风格（必须一眼能分清）

今日陪伴 → 右下角 →「轻轻安排」→ 角色选「女」→「更换角色风格」。

| 风格 | id | 应看到 |
| --- | --- | --- |
| 御姐 | `yujie` | 更高更长、深酒红西装长裙、长直发 |
| 萝莉 | `luoli` | 圆头身、双马尾、粉杏灯笼袖短裙 |
| 清纯风 | `qingchun` | 中等头身、半扎发、白衬衫浅色百褶裙 |

三张今日陪伴大图并排放时，不看字也能分开。菜单里也有同一套小预览。

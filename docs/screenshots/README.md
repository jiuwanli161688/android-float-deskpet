# 1.3 画面核对

本环境没有 Android 模拟器，未能实机截图。请用归档包核对：

```bash
adb install -r releases/float-deskpet-1.3.0-debug.apk
```

| 画面 | 怎么走到 | 应看到 |
| --- | --- | --- |
| 走进来 | 首次打开 | 标题「先回来一下」，账号/密码，链到登记 |
| 留下痕迹 | 点「去留下一点痕迹」 | 账号、密码、确认密码、昵称；非法账号有中文提示 |
| 今日陪伴 | 走进来并完成入驻 | 大角色图，标题「今日陪伴」，不是「首页」 |
| 右侧菜单 | 点右下角小按钮 | 从右侧滑入「轻轻安排」，可换装/请来身边/开关 |
| 我的小窝 | 右上角称呼，或菜单里「去我的小窝」 | 昵称、账号、幸福点 |
| 女风格 | 菜单里改成女，点御姐/萝莉/清纯风 | 大图色调与换装跟着变 |
| 男风格 | 改成男，点温柔邻家/清爽少年/沉稳学长 | 无睡衣；风格芯片与大图会变 |

核对账号：只许字母数字、5–18 位，提交时才报错。卸掉再装，同一台手机还能用刚才的账号走进来。

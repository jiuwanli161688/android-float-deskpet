# 1.3 画面核对

```bash
adb install -r releases/float-deskpet-1.3.1-debug.apk
```

| 画面 | 怎么走到 | 应看到 |
| --- | --- | --- |
| 引导 | 全新安装首次打开 | 四页：先坐一会儿 / TA 会自己待着 / 都只留在这台手机 / 以后让 TA 浮到窗边；可「先跳过」或「开始」 |
| 走进来 | 引导结束后 | 标题「先回来一下」，账号/密码，链到登记 |
| 留下痕迹 | 点「去留下一点痕迹」 | 账号、密码、确认密码、昵称 |
| 今日陪伴 | 走进来并完成入驻 | 大角色图，标题「今日陪伴」 |
| 右侧菜单 | 点右下角小按钮 | 从右侧滑入「轻轻安排」 |
| 我的小窝 | 右上角称呼，或菜单里「去我的小窝」 | 昵称、账号、幸福点 |
| 女风格 | 见下方 | 大图色调与换装跟着变 |
| 男风格 | 改成男，点温柔邻家/清爽少年/沉稳学长/大叔 | 无睡衣；风格芯片与大图会变 |

引导只出现一次。卸掉重装才会再看到。

## 女风格截图（协调员）

进入「今日陪伴」→ 右下角小按钮打开「轻轻安排」→「角色」选「女」→「更换角色风格」点芯片。大图在左侧/底下仍看得到。

| 风格 | id | 建议换装 |
| --- | --- | --- |
| 御姐 | `yujie` | 出行 |
| 萝莉 | `luoli` | 睡衣 |
| 清纯风 | `qingchun` | 日常 |

# 1.4.0 今日陪伴

本地桌宠。不联网、不生成对话、不用在线语音。

## 怎么用

1. 打开「今日陪伴」。顶上一句「今日一句」，点一下换同一时段的另一句。
2. 中间是大角色：点、长按、喂、动，和浮层同一套。
3. 角色下面是关系阶段（初识 / 熟络 / 默契 / 羁绊）和细进度，右边「连续 N 天」。
4. 三个今日小事：摸 / 喂 / 动。做完会亮。点芯片也能做。
5. 小心形数字是幸福点。喂会花；每天会慢慢补一点。提示「明天会慢慢回来」。
6. 右下角「轻轻安排」：请来身边、偶尔想你了（默认关）、声音、体型外观、账号小窝。让 TA 休息在最下面。
7. 浮层长按：摸摸 · 投喂 · 动一动 · 回主页 · 晚安。回主页只把今日陪伴唤到前面，不停陪伴。首页在前时浮层会藏起来。

## 本地怎么算

- 关系分 = 亲密度×0.7 + 心情×0.3。0–24 初识，25–49 熟络，50–74 默契，75–100 羁绊。熟络起句子会稍多一点。以后换装只预留口子，这版不发新衣服。
- 今日一句：早 6–10 / 午 11–16 / 晚 17–21 / 夜 22–5，按男女和风格从本机句子里取。点卡片换同池另一句。
- 连续天数：当天打开过首页，或浮层真正挂上，记一天。隔天续上，断了从 1 再来。3 / 7 / 14 / 30 天会轻轻说一句。
- 幸福：每天最多补 8 点，补到 120 就不再补。摸摸另加，喂照旧花。
- 今日小事：每项第一次完成 +2 幸福 +1 亲密；三项都完成再 +4 幸福 +2 亲密。第二天清零。
- 想你了：默认关。打开后下午和晚上最多各一声，四个小时内刚摸过就不说。静音时不说。通知里可「先不要提醒」。

## 不做

AI 对话、在线语音、商店、联网。

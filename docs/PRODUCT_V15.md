# 1.5.0

本地陪伴。不联网、不生成对话、不用在线语音。

## 1.4.1 打磨

- 浮层长按：五个纸片按钮排成浅扇（中间略高），顺序仍是 摸摸 · 投喂 · 动一动 · 回主页 · 晚安。贴边会翻到空处。
- 关系升阶：浅珊瑚色光晕 + 轻轻放大 +「走近了一点」，1.5 秒内，点角色可打断。
- 轻轻安排去掉穿透说明和机型说明。留下：陪伴、提醒（想你了默认关）、声音、体型外观、账号小窝；让 TA 休息在最下面。
- 今日小事亮起时卡片略抬高。回主页、首页在前藏浮层，都还在。

## 1.5 日子

- 「今天 TA 想…」：按风格和早午晚夜从本机句子里取。点一下可换。熟络以后句子会多一点。
- 小窝图鉴：抽屉「去小窝图鉴看看」。第一次见面、摸摸、喂、动、3/7/14/30 天、熟络/默契/羁绊、今天想做的事、收着的一天。没亮的卡片会温柔说明怎么亮。
- 阶段解锁：熟络打开日程味道和图鉴；默契画像略暖；羁绊多一张纪念。已解锁的随时能翻。

## 怎么试

1. 打开今日陪伴，看今日一句和「今天 TA 想…」，点卡片换一句。
2. 摸 / 喂 / 动，芯片亮起。
3. 轻轻安排 → 小窝图鉴，应看到新亮的卡片。
4. 请来身边，回到桌面，长按浮层：扇形菜单，点回主页。
5. 想你了默认是关的。
